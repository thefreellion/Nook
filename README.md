# React + Vite Project

## Installation

Clone the repository and install dependencies.

```bash
git clone https://github.com/thefreellion/Nook.git
cd Nook
npm install
```

---

## Running the Development Server

Start the local development server:

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```

This uses the **Vite development server for fast hot-reload during development.

---

## Build for Production

To build the project for production:

```bash
npm run build
```

The optimized production build will be generated in:

```
/dist
```

This folder contains the static assets ready to deploy.

---

## Deployment

You can deploy the contents of `/dist` to any static hosting service such as:

* **Cloudflare Pages**
* **Vercel**
* **Netlify**
* Any static web server

Typical deployment flow:

```bash
npm run build
```

Upload the `/dist` folder to your hosting provider.
